Our new Mac Book computers will now allow us to use Unity, the creative 2D/3D programming platform for creating Games and Multimedia applications. For those of you that wish to learn Unity may I ask that you start at the Essentials project please.              

https://learn.unity.com/learn/pathway/unity-essentials

We will be downloading this on to all the Mac Books as a starting point. If you want to do this on your computers at home, please download the Unity HUB and install the latest Unity Editor. It is best to have an account with Unity to keep track of your progress, so please ask a parent if you do not yet have an email account.

You can then download the Essentials Project from the link above and then Add it as a project from the Unity Hub application.

When you open the project from Unity Hub, you are guided through the missions.
