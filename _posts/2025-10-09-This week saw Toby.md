This week saw Toby doing more Python game coding and finding out about Integers and Floating point variables and how they do not get on very well with each other at times! We found that a = b/c returns a float, so if you are wanting to return an integer value, write a = b//c  (Welcome to the wonderful world of syntax).

Our Unity coders (Thomaz and Aleks) were having issues with their C# scripts and textures. Advice is to find an example online and work out how it works before trying to change any of the code. Make small changes and save working versions often, so you can go back small steps.
