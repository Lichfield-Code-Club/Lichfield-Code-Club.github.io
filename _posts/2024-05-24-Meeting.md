Summary of Club Meeting on Wednesday 22nd May

Max had finished his ping pong game, which was a python based game. In order to move on, Max started looking into creating web pages. He was able to use a template to create a website based on Liverpool football club. He created title, paragraph, table, and images elements. It was an impressive start to using HTML. His mum was happy too!

Somehow, Tomasz had got into a state where he could only run his graph plotting program if he started it with admin privileges. Once we realised the cause of the issue he was able to plot some bar charts without out much difficulty. He then started looking into how he could add a different function to the code to draw the same data as a pi chart. For home work he was tasked with sorting out the admin issue.

Aleks  added collision detection to his bullets and so handled them being destroyed, which in programmatic terms is a good skill to acquire. It doesn't sound much but it involves a lot of logic which typically catches a lot of programmers out.

Bill had some issues with his Unity based 2D platform game but he seemed to make some good progress.

Natan sorted out the IP issues he had last week, by updating the software and removing the fixed IP address. He's also looking into how to install Home Assistant on a Raspberry Pi to integrate with our weather station project.
